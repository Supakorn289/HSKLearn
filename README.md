# HSK Daily Stack (A-Z) 📚🔥

แอปพลิเคชันเรียนรู้คำศัพท์ภาษาจีน HSK 3.0 (ระดับ 1, 2, 3) จัดคิวแบบ **A-Z Daily Quota System** ออกแบบด้วยสไตล์ **Neo-Brutalism EdTech ผสม Glassmorphism** สำหรับ Web และ Android APK พร้อมระบบเกราะป้องกันสตรีค (Streak Shield) และ Spaced Repetition

---

## 🎨 ฟีเจอร์เด่น (Features)
- **A-Z Daily Quota System:** ศึกษาคำศัพท์ 3 ระดับ (HSK 1, 2, 3) จัดคิวเรียงตามหมวดอักษร A-Z อัตโนมัติ
- **คลังคำศัพท์ HSK 1-3 สมบูรณ์ (2,294 คำ):** มีไฟล์ `full_vocab.json` บรรจุคำศัพท์ HSK 1-3 ครบถ้วนทุกหมวดอักษร A-Z พร้อมพินอิน คำแปลภาษาไทย ตัวอย่างประโยค และคำพ่วงความสัมพันธ์
- **ระบบไฟสถานะ "ติด/ดับ" (Daily Streak Toggle):**
  - **ไฟดับ (Dormant):** เมื่อยังทำภารกิจหรือควิซไม่เสร็จสิ้นประจำวัน ไอคอนเปลวไฟจะดับเป็นสีเทาเพื่อกระตุ้นให้ผู้เรียนเข้าฝึกฝน
  - **ไฟติด (Ignited 🔥):** เมื่อผ่านการทดสอบมินิควิซประจำวัน เปลวไฟจะสว่างเด้งเป็นสีส้ม/แดง พร้อมเพิ่มสถิติ Stack สะสม
- **3D Tactile Flashcard:** พลิกการ์ด 3 มิติสมจริง พร้อมตัวอย่างประโยค และเครื่องหมายพินอินแยกสีวรรณยุกต์ (Tone 1-4) Contrast สูง
- **Semantic Cluster Diagram:** แสดงผังคำตรงข้าม (`ANTONYM` ⚡ VS), สเกลไล่ระดับ (`SPECTRUM`), และคำคู่ไวยากรณ์ (`SYNONYM_PAIR`) พร้อมกดฟังเสียงพูดได้ทันที
- **Offline Text-to-Speech:** เล่นเสียงอ่านภาษาจีนความเร็วปกติ 1.0x และสปีดช้า 0.65x
- **Spaced Repetition & Streak Shields:** สะสมเกราะน้ำแข็งป้องกันสตรีคขาด และบันทึกประวัติการเรียน Recharts 30 วัน

## 🚀 วิธีรันโปรเจกต์ (Local Development)

```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มต้น Dev Server
npm run dev
```

---

## 📥 วิธีนำเข้าคลังคำศัพท์สมบูรณ์ (2,294 คำ) เข้าแอป

ในโปรเจกต์นี้มีไฟล์ `full_vocab.json` ที่รวบรวมคำศัพท์ HSK ระดับ 1, 2, และ 3 ไว้อย่างครบถ้วนสมบูรณ์แล้ว ไม่จำเป็นต้องใช้ API Key ใดๆ:

1. เปิดแอปบนเบราว์เซอร์หรือมือถือ
2. ไปที่แท็บล่างขวา **"สถิติ & ตั้งค่า"** (Settings)
3. ในส่วน *สำรองข้อมูล & กู้คืน (Backup / Restore)* กดปุ่ม **"นำเข้าข้อมูลจาก JSON"**
4. เลือกไฟล์ `full_vocab.json` ในโฟลเดอร์โปรเจกต์
5. ระบบจะโหลดและอัปเดตคำศัพท์ทั้ง **2,294 คำ** เข้าสู่คลัง A-Z ของคุณทันที!

## 📱 การ Build เป็น Android APK (Capacitor)

โปรเจกต์นี้รองรับ Capacitor สำหรับคอมไพล์เป็นแอปมือถือ Android:

```bash
# 1. Build Production Assets
npm run build

# 2. ซิงก์โค้ดเข้า Android Studio Project
npx cap sync android

# 3. เปิดใน Android Studio เพื่อสร้าง APK
npx cap open android
```
